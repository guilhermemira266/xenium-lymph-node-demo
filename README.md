# xenium-lymph-node-demo

Live Colab demo: real Xenium 5K human lymph node spatial analysis — built for the WCI 2026 single-cell/spatial transcriptomics course (CSBL).

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/guilhermemira266/xenium-lymph-node-demo/blob/main/demo_xenium_lymph_node.ipynb)

## Contents

- `demo_xenium_lymph_node.ipynb` — the live notebook. Opens directly in Colab via the badge above; the dataset downloads automatically from this repo's [release assets](../../releases), no manual upload needed.
- Dataset: a public 10x Genomics Xenium Human 5K panel dataset (reactive human lymph node, 8,677-cell crop with real cell segmentation boundaries).
